# 韓服官網搜尋與公告預覽資料規格

## 目標

讓資料流程以韓服官方公告的「標題＋內容」搜尋為主要發現來源，再以公告正文作為品類、販售位置、韓服上線日、預覽圖片與染色碼的權威來源。

## 使用者可見的產品類型

資料集保留既有 `category` 欄位相容性，另外新增 `productType` 作為可篩選、可搜尋的細分類：

- 時裝幸運盒
- 寵物幸運盒
- 傳說時裝
- 套組
- 通行證
- 活動時裝
- 聯名時裝
- 商店時裝
- 樂器
- 染色劑選擇箱
- 新造型
- 特殊活動抽獎盒

一篇公告可以有一個主要 `productType`，以及零個以上的 `relatedTypes`。例如「캣스티벌 행운 상자」主要是特殊活動抽獎盒，正文內的樂器選擇箱與武器選擇箱則記錄在 `relatedTypes` 和 `components`。

## 搜尋詞

官方搜尋使用以下韓文詞組，並搜尋公告板的標題＋內容：

- `전설 패션`, `토탈 패키지`, `패션 럭키박스`, `펫 럭키박스`
- `모험가 프리미엄 패스`, `시즌 패스`, `컬렉션 백`
- `패션샵`, `패션 상점`, `패키지`, `신규 상품`
- `악기 선택 상자`, `악기`, `염색약 선택 상자`
- `헤어`, `헤어스타일`, `신규 외형`, `미리보기`
- `콜라보 상품`, `콜라보`, `컬래버`, `행운 상자`, `선택 상자`

搜尋結果只用來發現公告 ID；詳細內容仍會由公告 URL 抓取，避免搜尋結果摘要被當成完整資料。

## 圖片與染色資料

- `contentImages` 保存公告內所有符合官方 CloudFront 路徑的圖片，排除網站模板圖片。
- `galleryImages` 供網站檢視公告宣傳圖與預覽圖；除染色劑選擇箱外，不因「不是主宣傳圖」而丟棄預覽圖片。
- 染色劑選擇箱不需要下載預覽圖，正文中的 `#RRGGBB` 色碼保存到 `colorCodes`。
- 圖片只作輔助展示，不用圖片上的日期覆寫正文中的販售開始日期。

## 驗收條件

1. 3521630 能被「신규 상품」或「헤어／미리보기」搜尋發現，分類為新造型，保留兩張新髮型預覽圖與公告販售位置。
2. 3511363 能被「행운 상자」搜尋發現，分類為特殊活動抽獎盒，保留樂器與武器預覽圖及正文組成品名。
3. 3311070 保留活動公告內的服裝、臉部貼紙與非染色預覽圖，染色部分只顯示色碼。
4. 不影響既有台服比對、官方台服上線日與現有 `category` 相容性。
5. 以測試先驗證搜尋結果解析、分類優先序、色碼擷取與圖片排除規則，再執行資料建置與全套測試。
